# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Apple Liquid Glass Studio, please do NOT file a public issue.

Please report security concerns directly via GitHub Private Vulnerability Reporting or contact the maintainers. We appreciate your efforts to responsibly disclose findings and will respond within 48 hours to assess and mitigate any valid issue.
